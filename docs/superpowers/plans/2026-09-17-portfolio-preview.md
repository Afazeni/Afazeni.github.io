# 个人作品集初版实施计划

**目标：** 根据已确认的 Elijah Young 参考风格，完成可本地预览的中英双语结构设计作品集。

**架构：** 沿用 GitHub Pages 仓库，使用无构建依赖的 HTML、CSS、JavaScript。共享内容数据、导航和页脚；项目页通过固定项目标识读取内容；证书独立展示。原始素材保留在桌面，网站只使用优化后的副本。

## 已确认的设计

- 浅色固定导航、深色作品背景首屏、酒红按钮、大姓名与圆形肖像。
- 中文默认，提供英文切换；页面间保留语言选择。
- 首页突出四个队长项目，项目页讲清个人贡献、机构方案与仿真过程。
- 荣誉证书单独页面展示，支持年份筛选及键盘可操作的大图预览；专利准确标注申请公开。
- 提供公开版简历与联系方式；简历省略户籍、政治面貌，不覆盖原件。

## 验收场景

1. 首页四项作品均可进入对应详情，无证书图片混入作品区域。
2. 在任意页面切换英文，刷新、导航与返回时保持语言，标题和主要正文均切换。
3. 证书按年份筛选后可打开大图，Escape 关闭并恢复焦点；手机菜单可展开与关闭。
4. 联系链接有效，邮箱复制有状态反馈，公开简历 PDF 可打开和下载。
5. 桌面、平板和手机无水平溢出，图片与视频可加载，不自动播放带声音视频。
6. 代码、预览和原始资料保持分离，本次仅本地预览，不推送或发布。
